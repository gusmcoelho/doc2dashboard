# doc2dashboard

> Converte documentos (Word, PDF, Excel, CSV) em dashboards visuais automáticos — sem necessidade de programar.
>
> Converts documents (Word, PDF, Excel, CSV) into automated visual dashboards — no coding required.

## 🇧🇷 Português

### Como Usar

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/gusmcoelho/doc2dashboard.git
   cd doc2dashboard
   ```

2. **Instale as dependências:**

   ```bash
   npm install
   npm --prefix server install
   npm --prefix client install
   ```

3. **Inicie o servidor e o cliente:**

   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   Abra [http://localhost:5173](http://localhost:5173) e faça o upload de um arquivo `.docx`, `.pdf`, `.xlsx` ou `.csv`.

### Tecnologias Utilizadas

- TypeScript
- Node.js + Express
- React + Vite
- Recharts
- Jest
- ESLint + Prettier
- Antigravity IDE
